Simulador do Algoritmo CYK

Simulação do algoritmo CYK para reconhecimento de cadeias em Gramáticas Livres de Contexto.

Entrada

Uma produção por linha.
Use: S -> AB ou A -> a.

Como usar

1. Informe uma gramática na Forma Normal de Chomsky.
2. Informe a cadeia.
3. Clique em Executar para preencher toda a tabela e construir a árvore.
4. Use Próximo passo para acompanhar a execução passo a passo.
