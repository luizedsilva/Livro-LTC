    Trecho de código correspondente

    void qSort(int m, int n) {
    if (n > m) {
        int i = partition(m, n);
        qSort(m, i - 1);
        qSort(i + 1, n);
    }
}

    O simulador detalha a árvore de chamadas e os registros de ativação. A função partition é executada como parte de cada ativação não-base e atualiza o vetor.
